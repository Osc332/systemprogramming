# Задача 1.1. Ядро агента на C

Коротко: нужно было написать на C функцию, которая возвращает данные о системе (PID процесса, число CPU, размер страницы, имя компьютера), собрать её в обычную программу и убедиться, что всё печатается.

## Что лежит в agent/core

- `core.h` — заголовок со структурой `core_info` и объявлением функции.
- `core_info.c` — сама функция `core_get_info`, отдельно для Windows и для UNIX-систем. У меня Windows, поэтому активна ветка с `#include <windows.h>`.
- `show_info.c` — маленькая программа с `main`, которая вызывает функцию и печатает результат. Нужна просто чтобы проверить, что ядро работает.

## Структура

```c
struct core_info {
    int64_t pid;
    int32_t cpus;
    int32_t page_size;
    char    host[CORE_HOST_MAX];   /* 256 байт */
};
```

Итого 8 + 4 + 4 + 256 = 272 байта. Это число потом пригодится в 1.2.

## Как функция работает на Windows

- `GetCurrentProcessId()` — PID.
- `GetNativeSystemInfo()` — число процессоров и размер страницы.
- `GetComputerNameW()` — имя компьютера, оно в UTF-16. Перевожу в UTF-8 через `WideCharToMultiByte`, иначе в Python потом некрасиво читается.
- Если что-то не так — возвращаю код ошибки через `GetLastError()`. При успехе возвращаю 0.

Ещё в начале стоит проверка `if (out == NULL) return ERROR_INVALID_PARAMETER;`. Сделал её специально — в 1.2 проверим, что она спасает от падения.

## Как собрать

Собирал в **x64 Native Tools Command Prompt for VS 2022**, в обычном cmd `cl` не находится.

```bat
cd C:\SysProg\agent\core
cl /nologo /W4 core_info.c show_info.c /Fe:show_info.exe
show_info.exe
```

У меня получилось примерно так:

```text
pid=15344 cpus=10 page_size=4096 host=DESKTOP-XXXXXXX
```

`page_size` на Windows всегда 4096 (4 КБ). На macOS было бы 16384 — это нормально, разные архитектуры.

## Что пошло не так

Сначала собирал в обычной командной строке, `cl` не было. Потом прочитал, что VS ставит «среду разработчика» только через специальное окно. Открыл x64 Native Tools — заработало.

Ещё была проблема с кодировкой: один раз VS Code сохранил `core_info.c` в cp1251, MSVC ругнулся на недопустимый символ. Решается через File → Save with Encoding → UTF-8.

## Итог

Ядро работает, `show_info.exe` печатает данные. Дальше в 1.2 эту же функцию загружаем из Python через DLL.
