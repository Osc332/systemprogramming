# Задача 1.1. Ядро агента на C

В чем суть: нужно было написать на C функцию, которая возвращает данные о системе (PID процесса, число CPU, размер страницы, имя компьютера), собрать её в обычную программу и убедиться, что всё печатается.

## Что лежит в agent/core

- `core.h` — заголовок со структурой `core_info` и объявлением функции.
- `core_info.c` — сама функция `core_get_info`, отдельно для Windows и для UNIX-систем. У меня Windows, поэтому активна ветка с `#include <windows.h>`.
- `show_info.c` — маленькая программа с `main`, которая вызывает функцию и печатает результат. Нужна просто чтобы проверить, что ядро работает.
