# Лабораторная работа 3. Библиотеки программы

**Система:** Windows 11 (x64), компилятор MSVC 19.44.35219 (`cl.exe`).

## Библиотеки файла
Программа напечатала: `sqrt(2) = 1.414214`.

Команда для списка библиотек файла: `dumpbin /dependents libs.exe`.

Библиотеки `libs.exe`: `KERNEL32.dll`.

**Почему в списке нет отдельной математической библиотеки:** в Windows при сборке через MSVC отдельной математической библиотеки, аналогичной `libm` в Linux, в списке динамических зависимостей может не быть. В данном случае `sqrt(2)` имеет константный аргумент, поэтому компилятор мог вычислить значение ещё на этапе компиляции. Кроме того, CRT в MSVC подключается иначе, чем `libm` в Linux. У `python.exe` математика при этом может быть подключена динамически, например через `api-ms-win-crt-math-l1-1-0.dll`.

**Где лежит интерпретатор Python:** исполняемый файл `C:\Users\Георгий\AppData\Local\Microsoft\WindowsApps\python.exe`; основная библиотека интерпретатора — `C:\Users\Георгий\AppData\Local\Programs\Python\Python313\python313.dll`.
